## 已体现的关键业务口径（2026-09-16/17 规则校准）

- 调解费 = 诉讼费（全国统一标的额分段标准）× 法院比例（40%–50% 逐法院预置）
- 提成核算原值 = 实收调解费总和；标的额仅用于业务风险判断
- 案件时效：简易程序 7 天 / 普通程序 15 天；延期仅 1 次、固定 30 天
- 退案管理：申请返回审核 → 退案池 → 人工重新指派（直接换人，不参与智能分案）
- 网页端 AI 智能体：案件内侧边栏形态，后端中转（前端零密钥）、会话绑定 case_id、输出仅供办案参考

## 技术说明

纯 HTML + CSS + JS，零构建、零依赖。侧边栏菜单由 `assets/app.js` 按角色注入；交互按钮均为演示 mock（弹窗提示），不产生实际数据变更。
