## 一、需求背景与价值

### 1.1 模块定位

首页与登录模块是用户访问问问调解平台的第一入口，承担以下核心职能：
1. **平台形象展示**：展示问问调解平台的品牌形象、功能优势和服务价值
2. **每日调解摘要**：提供调解行业政策解读、案件分析和资讯呈现（第一阶段由运营手工发布或静态占位，AI 自动生成随后续阶段启用）
3. **用户登录入口**：支持系统管理员、调解员两种登录身份（调解员可带主管标识，登录时无需区分）
4. **新用户注册**：支持手机号验证码注册，经管理员审核后开通账号

### 1.2 业务价值

- 对公众：无需登录即可了解平台定位与服务能力，降低合作法院与调解组织的认知门槛；
- 对用户：注册即自动发起机构绑定申请，账号审核与数据可见性开通一次打通；
- 对平台：账号审核 + 角色两值化（系统管理员/调解员）保证权限模型简洁可控。

---

## 二、需求目标

1. 交付 4 个公共页面：平台首页、登录页、注册页、注册成功页（均 P0，公开访问）。
2. 登录支持系统管理员/调解员两种身份选择，调解员主管标识在登录环节不区分，登录后按标识动态显示专属功能。
3. 注册采用手机号验证码方式，注册提交后自动生成"法院+调解组织"机构绑定申请，进入管理员审核流。
4. 每日调解摘要板块第一阶段空缺占位，后续阶段由自动化信息抓取生成。

## 三、适用角色

| 角色 | 使用方式 |
|-----|---------|
| 公众访客 | 浏览平台首页、功能介绍（无需登录） |
| 系统管理员 | 登录页选择「系统管理员」身份登录，进入调解驾驶舱；账号由平台管理员直接创建，不支持自助注册 |
| 调解员（含/不含主管标识） | 登录页统一选择「调解员」身份登录，进入调解工作台；可通过注册页自助注册 |
| 新注册用户 | 注册后账号状态为待审核，审核通过后方可登录使用 |

## 四、权限规则（页面/按钮/行数据权限）

### 4.1 页面权限

| 页面 | 访问权限 | 说明 |
|-----|---------|------|
| 平台首页 | 公开 | 每日调解摘要+平台介绍+登录入口 |
| 登录页 | 公开 | 已登录用户访问自动跳转对应首页 |
| 注册页 | 公开 | 手机号验证码注册+信息填写 |
| 注册成功页 | 公开 | 提示等待管理员审核 |
| 管理端全部页面 | 仅系统管理员 | 未授权访问重定向到对应首页 |
| 操作端全部页面 | 调解员（含/不含主管标识） | 主管专属页面在页内按主管标识控制 |

### 4.2 按钮权限

| 按钮 | 归属与规则 |
|-----|----------|
| 立即登录 | 公开；登录时按选中角色进行身份验证 |
| 立即注册 | 公开；注册统一申请调解员角色 |
| 获取验证码 | 公开；手机号格式校验通过后可用，60 秒倒计时 |
| 登录/注册提交 | 公开；须通过表单校验（见第9章） |
| 忘记密码 | 公开入口（流程为后续规划） |

### 4.3 行数据权限

- 登录后用户仅按角色进入对应端：系统管理员→管理端，调解员→操作端；
- 主管专属功能（法院数据全景、审批结案、全组收益明细查阅）由账号属性决定，登录环节不选择；
- **数据可见性前置**：账号审核通过但机构绑定未通过时，登录后不可见任何法院数据，系统提示并引导前往"我的机构绑定"（详见《01》《04》）。

### 4.4 访问控制规则（业务口径）

- 用户访问受控页面：未登录 → 引导到登录页；已登录但角色不符 → 重定向到其角色对应首页；
- 已登录用户访问登录页：系统管理员→调解驾驶舱，调解员→调解工作台；
- 主管专属内容的可见性在页面内按主管标识判断，与登录身份选择解耦。

## 五、业务流程

### 5.1 登录流程

```
用户访问登录页
    │
    ▼
选择登录角色（默认调解员）
    │
    ▼
输入用户名/手机号和密码
    │
    ▼
点击登录按钮
    │
    ▼
表单校验
    ├─ 校验失败 → 显示错误提示，停留在登录页
    └─ 校验通过 → 提交身份验证
              │
              ▼
         后端身份验证
         ├─ 验证失败 → 返回错误信息（账号不存在/密码错误/角色不匹配/账号未审核/账号已停用）
         └─ 验证通过 → 登录态建立
                   │
                   ▼
              根据角色跳转对应首页
              ├─ 系统管理员 → 调解驾驶舱
              └─ 调解员（含/不含主管标识）→ 调解工作台（主管专属功能按标识动态显示）
```

### 5.2 注册流程

```
用户填写注册表单
    │
    ▼
表单校验
    ├─ 校验失败 → 显示对应字段错误提示
    └─ 校验通过 → 提交注册申请
              │
              ▼
         后端校验（手机号是否已注册、验证码是否正确）
         ├─ 校验失败 → 返回错误信息
         └─ 校验通过 → 创建用户账号（状态：待审核）
                   │
                   ▼
              跳转到注册成功页
              （提示：注册申请已提交，请等待系统管理员审核）
```

**注册后处理（对齐《01》机构绑定衔接）**：
1. 账号状态置为待审核；
2. 系统自动将注册时选择的法院+调解组织生成一条机构绑定申请；
3. 系统管理员审核通过后账号激活、绑定生效，数据可见性即时开通；账号通过但绑定未通过时，登录后不可见任何法院数据（提示并引导去"我的机构绑定"）。

### 5.3 验证码发送流程

```
用户点击"获取验证码"按钮
    │
    ▼
校验手机号格式
    ├─ 格式错误 → 提示"请输入正确的手机号"
    └─ 格式正确 → 发送短信验证码
              ├─ 发送失败 → 提示"验证码发送失败，请稍后重试"
              └─ 发送成功 → 按钮变为"60秒后重新获取"，倒计时60秒
                        │
                        ▼
                   倒计时结束后按钮恢复为"获取验证码"
```

**每日调解摘要板块**：核心内容板块，内容包括政策解读（全国及地方关于调解案件的政策法规解读）、案件分析（典型调解案例的深度分析和经验总结）、行业资讯（调解行业的最新动态、新闻和趋势）。内容来源：第一阶段板块空缺占位（不发布内容）；后续阶段通过自动化信息抓取流程生成（随 AI 智能体模块一并启用，见《00》第二阶段范围）。每个摘要卡片包含：分类标签、标题、摘要内容（2-3行）、发布日期、点击跳转详情页（后续规划）。

**平台功能介绍板块（8大核心功能）**：智能分案（基于三维度权重的智能案件分配）、案件管理（全流程案件管理，多标签页详情）、外呼记录（时间线管理，录音上传）、文书生成（系统模板+自定义模板，一键生成）、AI赋能（案件智能分析，类案检索，调解策略建议）、法规库（法规查询引用）、数据看板（实时动态BI可视化）、财务核算（调解员标签体系，收益自动核算）。

**顶部导航栏**：Logo（蓝色渐变背景，与登录页按钮颜色一致）、导航菜单（首页、功能介绍、关于我们，点击滚动到对应板块）、登录按钮（右上角，跳转登录页）。

## 八、增删改查流转规则

| 对象 | 规则 |
|-----|------|
| 用户账号-增 | 仅注册页自助申请（调解员）与管理员创建（系统管理员）两条途径；注册创建后状态为待审核 |
| 用户账号-查 | 登录验证、账号信息展示 |
| 用户账号-改 | 审核通过/驳回、启用/停用、主管标识勾选等由系统管理员在人员管理完成（见《03》）；本模块不提供修改入口 |
| 用户账号-删 | 本模块不提供删除入口 |
| 机构绑定申请-增 | 注册时按"法院+调解组织"自动生成一条待审核绑定申请；登录后可在"我的机构绑定"继续申请（见《04》） |
| 机构绑定申请-审 | 由系统管理员审核（见《03》），通过后数据可见性开通 |
| 登录态 | "记住我"7天内免登录；会话超时时长在系统设置安全配置（见《03》） |
| 验证码 | 60秒倒计时防重发；有效期与使用次数约束以附件《06》为准 |

## 九、校验&异常场景

### 9.1 登录错误提示

| 错误场景 | 提示信息 | 显示位置 |
|---------|---------|---------|
| 用户名/手机号为空 | 请输入用户名或手机号 | 输入框下方 |
| 密码为空 | 请输入密码 | 输入框下方 |
| 账号不存在 | 该账号不存在，请检查后重试 | 表单顶部红色提示 |
| 密码错误 | 密码错误，请重新输入 | 表单顶部红色提示 |
| 角色不匹配 | 该账号不是系统管理员，请选择正确的角色 | 表单顶部红色提示 |
| 账号未审核 | 账号正在审核中，请耐心等待管理员审核 | 表单顶部黄色提示 |
| 账号已停用 | 账号已被停用，请联系管理员 | 表单顶部红色提示 |
| 网络错误 | 网络异常，请稍后重试 | 表单顶部红色提示 |

### 9.2 注册校验与异常

| 场景 | 校验/处理规则 |
|-----|--------------|
| 手机号格式 | 11位有效手机号，格式错误即时提示 |
| 手机号已注册 | 提交时校验，返回错误信息 |
| 验证码错误 | 提交时校验，返回错误信息 |
| 验证码获取 | 手机号格式校验通过才可发送；发送失败提示稍后重试；60秒倒计时防重发 |
| 密码强度 | 6-20位，包含字母和数字；两次输入一致 |
| 姓名格式 | 2-20位中文或英文 |
| 法院/组织必填 | 调解员注册时二者成对必填，下拉来源为主数据 |
| 用户协议 | 必须勾选方可提交 |
| 重复提交 | 提交期间按钮防重复点击 |

### 9.3 登录后异常场景

| 场景 | 处理规则 |
|-----|---------|
| 账号通过但机构绑定未通过 | 登录后不可见任何法院数据，提示并引导前往"我的机构绑定" |
| 访问非本角色页面 | 重定向到其角色对应首页 |
| 已登录访问登录页 | 自动跳转对应首页（管理员→驾驶舱，调解员→工作台） |
| 主管标识差异 | 登录环节不区分，登录后按标识动态显示主管专属功能，无标识者不可见 |

## 十二、非功能需求

1. **公开可用性**：平台首页、登录、注册页面对公众开放，不依赖登录态。
2. **视觉一致性**：登录/注册/首页统一蓝色渐变主题（#409eff → #66b1ff），规范见第 6.3 节视觉设计规范。
3. **注册审核时效**：界面承诺预计审核时间 1-3 个工作日；实际时效由运营流程保证。
4. **安全性**：密码 6-20 位含字母数字；验证码 60 秒倒计时防重发；"记住我"7 天免登录；会话超时与登录失败锁定策略在系统设置安全配置（见《03》）。
5. **占位模块约束**：每日调解摘要第一阶段空缺占位，不发布内容；后续阶段随 AI 智能体模块启用自动化生成。
